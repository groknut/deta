
# Deta

Пейджер для чтения табличных и не очень  данных.

## Сценарии вызова
**Справка:**
Вызов без аргументов, или с `--help`/`-h`
```bash
deta -h
```

## Поддерживаемые форматы

|**Формат**|**Поддержка**|**Отображение**|
|-------|-------|----|
|csv|Реализовано|Таблица|
|txt|В планах|Просто текст|
|sql|Реализовано|Таблица|
|json|В разработке|-|
|binary|Доработка|hex и ascii таблица|
|toml|В планах|-|
|yaml|В планах|-|

### Настройка

**Файл конфигурации** находится: `~/.config/deta.toml`

```toml
control = "vim"
```

**Режимы управления:**
|**Mode**|**Control**|
|-------|-------|
|vim|hjkl|
|default|arrows|

**Стек:**
1. Основной язык: golang
2. Библиотеки: bubble tea, testing, стандартные golang библиотеки
