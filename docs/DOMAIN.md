# Deta

Проект Data Viewer предоставляет консольный интерфейс для интерактивного просмотра файлов различных форматов.

Он создан для обучения разработчиков работе с терминальными TUI-приложениями и не предназначен для промышленной эксплуатации.

Разработчик может добавлять новые типы просмотрщиков, следуя единой архитектуре и переиспользуя общие компоненты.

## Что считается входными данными
Входные данные — файл на локальной файловой системе в одном из поддерживаемых форматов:

- бинарный (произвольные байты) — отображается в виде HEX-дампа;
- JSON (структурированные данные) — отображается в виде сворачиваемого дерева;
- SQL / CSV — табличное представление

Данные читаются полностью или поблочно, в зависимости от реализации конкретного ридера.

Основные сущности
Модуль просмотрщика (Reader)
Отвечает за открытие файла, парсинг, построение модели отображения и обработку пользовательского ввода.
Каждый тип данных реализуется отдельным модулем (binary, json, text…).

Отображаемая запись (Row / Line / Node)
Атомарный элемент интерфейса:

для бинарного ридера — одна 16‑байтовая строка HEX-дампа;

для JSON — один узел дерева (ключ + значение или контейнер);

для табличных данных — одна строка таблицы.

## Модель представления (ViewModel)
Внутреннее состояние просмотрщика, которое включает:
- подготовленный список отображаемых элементов;
- текущую позицию курсора / выделения;
- параметры отображения (например, свёрнутость узлов в JSON, количество строк на странице в бинарном режиме).

## Навигация и действия
Набор операций, доступных пользователю: перемещение курсора, скроллинг, раскрытие/сворачивание, выход.
Привязки клавиш к действиям определяются через KeyMap и могут быть изменены без модификации кода (в будущем).

## Ограничения области
В текущей версии:
- не реализована поддержка удалённых файлов (только локальная ФС);
- отсутствует обработка потокового ввода (stdin);
- не учитываются права доступа, блокировки файлов и конкурентный доступ;
- не интегрированы сетевые протоколы и облачные хранилища.
